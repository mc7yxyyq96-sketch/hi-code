# Historical Audit Archive

The files in this directory are historical snapshots from earlier v0.5.x review and repair cycles. They are retained as evidence, but their open/fixed counts are not current release status and must not be used to approve or block the current source tree without revalidation.

Current authority:

- Program state: `reports/program/status.md`
- Current risks: `reports/program/risks.json`
- Task results: `reports/tasks/`
- Machine-captured gates: `reports/evidence/`

Do not rewrite old audit outcomes to look current. When an old finding matters, create a current backlog/risk entry with fresh source evidence and acceptance criteria.
